# PRTI-GH aggregate results v1 archive

This is a retained technical appendix, not the primary reporting package.
Use [`../prti-results-v2/`](../prti-results-v2/) for current tables and figures.

Version 1 remains available because it contains detailed one-factor
sensitivity, baseline-cluster risk, and ranked sensitive-attribute risk tables
that are not reproduced verbatim in version 2. It is derived evidence and does
not contain patient rows.

Do not delete this directory until those unique tables have either been moved
into a later consolidated package or explicitly retired from the study scope.
